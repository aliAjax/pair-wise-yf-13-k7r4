# hxyfront-62001 船舶轮机值班记录

源提示词编号：1

面向船舶轮机值班的前端记录系统：机舱参数采样看板、活动报警确认闭环、异常时间线、交接班摘要与按设备筛选。数据保存在浏览器本地，无需后端，零新增依赖。

## 报警确认闭环规则

1. **越限建警**：采样值超出参数限值（闭区间外）时，按「设备 + 参数」生成一条活动报警；未恢复正常前，持续越限不重复新建，只累加越限次数。
2. **轮机员确认**：确认只关闭本班提示，报警仍留在看板；进入下一班后未恢复的报警自动重新提示。
3. **跨班升级**：下一班（或更晚班次）采样仍越限时，自动重新激活并升级为**严重**；首发的一般报警记录与升级时间都保留在时间线，级别不回退、不改写。
4. **严重补单消除**：升级后即使观测到采样恢复正常，也必须补**处理说明**和合格的**复测值**（须回到正常区间）才能消除；一般报警复测恢复正常即自动消除。
5. **交接班拦截**：本班存在未恢复的严重报警时，无法完成交接班；交接摘要列出遗留报警的设备与参数。
6. **刷新保留**：状态写入 `localStorage` 并监听多标签页 `storage` 同步；设备筛选、时间线、报警状态刷新后保留。

## 分层（无状态管理/组件库等新依赖）

- `src/types.ts` — 类型定义
- `src/rules.ts` — 限值规则与纯函数状态流转（采样、确认、升级、消除、交接班、初始数据）
- `src/store.ts` — localStorage 持久化、跨标签页同步、发布订阅容器与 React hook
- `src/components/*` — 页面部件（班次/交接、设备筛选、采样看板、报警看板、时间线）
