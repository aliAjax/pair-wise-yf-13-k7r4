# hxyfront-62001 船舶轮机值班记录

面向船舶轮机值班的前端记录系统：机舱参数采样、报警确认闭环、异常时间线、交接班摘要与按设备筛选的台账。数据保存在浏览器本地，不新增依赖或服务，刷新保留。

## 报警确认闭环规则

1. **越限建警（去重）**：参数越限时按「设备 + 参数」生成一条活动报警；未恢复正常前不重复新建，同班重复越限只刷新读数并向异常时间线追加一次采样事件。
2. **确认不关报警**：轮机员确认只关闭本班提示，报警仍留在活动看板；确认记录按班次留痕，下一班提示会重新出现。
3. **跨班重新激活与升级**：下一班采样仍越限时自动重新激活并升级为**严重**；原记录保持同一条、历史级别只追加不回改。
4. **严重报警闭环条件**：升级后即使复测回正常区间也不自动消除，必须**补处理说明 + 复测值**才能闭环；原级别保持「严重」。一般报警恢复正常即自动消除。
5. **交接班门禁**：本班存在未恢复的严重报警时不得完成交接班；交接摘要按「设备 · 参数」列出全部移交报警。
6. **闭环后**：已恢复/已闭环的报警再次越限视为一条全新活动报警。

## 分层结构（状态、规则与页面分开承载）

```
src/
├── types.ts                 领域模型：报警 / 事件 / 交接班
├── rules/
│   ├── parameters.ts        参数规则：设备、阈值、计量单位、越限判定（纯函数）
│   ├── shifts.ts            班次规则：六班循环、跨天序号、班次文案（纯函数）
│   └── alarms.ts            报警状态机：采样、确认、升级、闭环、交接门禁（纯函数）
├── state/
│   └── store.ts             状态编排：reducer + useSyncExternalStore + localStorage
├── lib/format.ts            展示层文案与时间格式
├── pages/DutyPage.tsx       值班页：组合各面板
├── components/              SamplingPanel / AlarmBoard / Timeline / History / HandoverPanel
└── react-shim.d.ts          类型垫片（脚手架无 @types/react，且不允许新增依赖）
```

- `rules/` 不 import React，不触碰存储，可独立单测。
- `state/store.ts` 是唯一读写 `localStorage` 的位置，写入即持久化，并监听 `storage` 事件做跨标签页同步；缓存损坏时安全回退为空态。
- 页面与组件只通过 `dispatch` / `useAppState` 访问状态。
- 设备筛选（全部 / 主机 / 发电机 / 泵组 / 舱底水）同时作用于活动看板、异常时间线与历史台账。
